# نور | بوابة الأعمال لمستحضرات التجميل

تطبيق React + Vite باللغة العربية وواجهة RTL، يعمل ببيانات تجريبية محلية ويشمل بوابة العميل ولوحة الإدارة. يستخدم `localStorage` لمحاكاة حفظ الحسابات والمنتجات والطلبات والسلة والإشعارات، ويمكن استبدال خدمات البيانات لاحقاً بطلبات Axios إلى API.

## التشغيل

```bash
npm install
npm run dev
```

لإنشاء نسخة النشر:

```bash
npm run build
npm run preview
```

إعداد Vercel موجود في `vercel.json` لدعم المسارات الداخلية عبر إعادة الكتابة إلى التطبيق.

## حسابات التجربة

- مدير النظام: `admin@nour.com` — كلمة المرور `admin123`.
- عميل نشط: `client8@example.com` — كلمة المرور `client123`.
- حسابات العملاء التجريبية الأخرى: `client1@example.com` إلى `client20@example.com` — كلمة المرور `client123`. حالات الدخول تتبع حالة الحساب في بيانات التجربة.
- يمكن إنشاء حساب جديد؛ يبدأ دائماً بحالة «قيد المراجعة».

## المسارات والميزات

- `/` كتالوج المنتجات: بحث وتصنيف وفرز وترقيم صفحات، وإظهار السعر الخاص بحساب العميل فقط وسعر المستهلك، والمفضلة والمقارنة.
- `/cart`, `/checkout`, `/orders`: السلة محفوظة محلياً، إنشاء طلب من دون حد أدنى أو ضريبة، وسجل الطلبات.
- `/profile`, `/export-prices`: ملف العميل وطلب تغيير الشريحة عبر واتساب، وتصدير قائمة السعر الخاصة به بصيغتي Excel وPDF.
- الإشعارات منفصلة حسب الدور: إشعارات التسجيل والطلبات للإدارة، وإشعارات الموافقة وتحديث الشريحة للعميل المعني فقط.
- `/login`, `/register`, `/forgot-password`, `/change-password`: المصادقة التجريبية والتحقق من المدخلات وحالات الموافقة.
- `/admin`: لوحة إحصائيات مع إدارة العملاء والمنتجات والتصنيفات والاستيراد والطلبات والأسعار وسجل التعديلات والإشعارات.
- `/admin/excluded-products`: مساحة موجودة لكنها تبدأ فارغة.

## استيراد المنتجات

من `/admin/import` ارفع ملف `.xlsx` أو `.xls` بأعمدة الصف الأول التالية:

`المعرف، رمز المنتج SKU، الاسم، وصف قصير، الوصف، تم النشر، هل هي مميزة، متوفر، المخزون، التصنيفات، العلامات التجارية، الصور، سعر التخفيض، السعر الافتراضي`

تعرض الأداة معاينة الصفوف وأخطاء التحقق قبل الحفظ. سعر التخفيض يصبح سعر القطعة، والسعر الافتراضي يصبح سعر المستهلك، والتصنيفات غير الموجودة تضاف تلقائياً. يتوفر قالب Excel للتنزيل من صفحة الاستيراد.

## التقنية والملاحظات

React 18، Vite، Tailwind CSS، React Router، Axios، SheetJS CE 0.20.3 (التوزيعة الرسمية)، React Hook Form، Zod، TanStack Query/Table، jsPDF، Lucide، Context API، وReact Hot Toast.

كتالوج `src/data/productCatalog.json` مستورد من ملف المنتجات المقدم: يضم 3298 صفاً، منها 1867 منتجاً منشوراً للعرض وفق إعداد النشر في الملف. روابط صور المنتج محفوظة كما وردت في الملف وتُحمّل من مضيف الصور الأصلي؛ المنتجات التي لا تحتوي على صورة أصلية تعرض مساحة محايدة بدلاً من استخدام شعار المتجر كصورة منتج. في الإنتاج ينبغي ربط المصادقة والتخزين والأسعار والطلبات بخادم API آمن، لأن `localStorage` والبيانات التجريبية مخصصة للعرض والتطوير وليست نظام صلاحيات إنتاجياً.
